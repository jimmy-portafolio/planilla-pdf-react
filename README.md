# Planilla PDF con React-PDF

Sistema de generación de planillas/proformas en PDF utilizando React-PDF.

## 🚀 Características

- Generación de planillas/proformas en formato PDF
- Diseño responsivo y profesional
- Separación de estilos y componentes
- Fácil personalización de datos

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/planilla-pdf-react.git

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
